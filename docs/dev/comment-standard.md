# 虞美人代码注释规范

本规范适用于虞美人（Yumeiren）Qt/C++ 项目的所有源代码。所有新增和修改的代码必须遵守。

---

## 一、核心原则

1. **注释解释"为什么"，不重复"做什么"**
2. **命名清晰的代码不需要注释** — `m_name = name;` 不需要 `// 设置名称`
3. **不为显而易见的代码加注释** — `return true;`、`++index;` 不需要注释
4. **注释必须描述真实行为** — 禁止猜测，必须验证后写入
5. **不要为了增加注释数量而添加注释** — 目标是降低理解成本，不是提高覆盖率

---

## 二、语言

- 默认使用简体中文
- 技术名称、API 名称、类名、枚举值保留英文
- 示例：`// 使用 QMediaPlayer 管理媒体播放状态。`

### 统一术语

| 统一术语 | 不建议混用 |
|----------|-----------|
| 看板娘 | 桌宠、桌面娘 |
| 动态壁纸 | 视频壁纸、动态背景（除非需区分类型） |
| 主窗口 | 主界面、设置窗口 |
| 系统托盘 | 托盘区、通知区域 |
| 播放器 | 视频播放器、媒体播放器 |
| 渲染器 | 绘制器、渲染模块 |
| 控制器 | 管理器（除非类确实是 Manager） |

## 三、文件级注释

每个 `.h` 文件和负责独立逻辑的 `.cpp` 文件应在顶部添加简短说明。

```cpp
/**
 * @file VideoWallpaper.h
 * @brief 动态壁纸核心类：视频播放、多屏输出、挂起策略与生命周期管理。
 */
```

要求：
- 不超过 5 行
- 说明文件职责
- 必要时说明不负责的内容
- 不写作者、创建日期
- 不写"本文件实现了某某功能"这类空泛描述

---

## 四、类级注释

以下类必须添加类级注释：
- 管理复杂资源的类
- 有明确状态机的类
- 涉及线程的类
- 涉及 Windows API 的类
- 涉及第三方 SDK 的类
- 跨模块公共接口
- 生命周期不直观的类

```cpp
/**
 * @brief 动态壁纸核心类。
 *
 * 负责视频播放、多屏输出、挂起/恢复策略和播放器生命周期管理。
 * 具体的窗口挂载由 desktopmount 负责，不在本类范围内。
 */
```

普通数据结构（POD、简单 struct）不需要过长注释，但语义不直观的成员必须逐行说明。

## 五、函数注释

### 公共接口

在以下情况添加注释：
- 参数含义不明显
- 返回值有特殊语义
- 会改变对象状态
- 会创建或释放资源
- 必须在特定线程调用
- 有调用顺序要求

```cpp
/**
 * @brief 启动看板娘。
 *
 * 如果已运行则不重复创建。Live2D 不可用时自动降级到占位动画。
 * @return 启动成功返回 true。
 * @note 必须在 Qt GUI 线程调用。
 */
bool start();
```

### 私有函数

函数名已清晰表达意图时，不需要注释。只在以下情况添加：
- 非直观的实现策略
- 平台特殊处理
- 资源释放顺序有讲究

---

## 六、状态变量注释

普通变量不需要注释。以下情况需要说明语义：

```cpp
// 用户是否主动暂停，而不是播放器因窗口不可见而暂停
bool m_manualPaused = false;

// 退出闸门：一旦置位，closeEvent 中「隐藏而不退出」必须失效
bool m_quitting = false;
```

---

## 七、复杂逻辑注释

### 状态机

```cpp
// 停止状态下允许重启；启动中重复请求直接忽略，避免重复创建播放器和窗口
if (m_state == State::Starting || m_state == State::Running)
    return;
```

### 资源释放

```cpp
// 先解除输出窗口与播放器的关联，再销毁播放器，
// 避免播放器销毁过程中仍持有输出对象引用
teardownOutputs();
m_player.reset();
```

### Windows 平台代码

必须说明 Windows API 的使用原因、窗口层级目的、Explorer 重启/DPI/HWND 相关限制。

## 八、Qt 专项

### QObject 父子关系

```cpp
// 由 Qt 父子对象机制负责销毁，控制器不应手动 delete
m_window = new KanbanWindow(this);
```

### QTimer

```cpp
// 定时器只驱动状态检查，不直接执行耗时操作，避免阻塞 GUI 线程
```

### 信号槽

```cpp
// UniqueConnection 避免重复连接
connect(sender, &Sender::stateChanged, receiver, &Receiver::updateState, Qt::UniqueConnection);
```

## 九、禁止的注释

| 类型 | 示例 |
|------|------|
| 无意义注释 | `// 构造函数`、`// 返回结果` |
| 重复代码含义 | `// 设置音量为 0` + `m_audioOutput->setVolume(0);` |
| 过度逐行注释 | 每行代码前都有注释 |
| 过时注释 | 注释与代码行为不一致 |
| 情绪化注释 | `// 这里很坑`、`// Qt 又抽风了` |
| 个人信息 | `// 作者：xxx`、`// 2026 年修改` |
| 无效 TODO | `// TODO: later`、`// FIXME: bug` |

## 十、TODO / FIXME / NOTE

只在确实存在后续工作时使用：

```cpp
// TODO: 支持多个模型目录的增量扫描
// FIXME: Explorer 重启期间可能出现短暂的桌面宿主窗口失效
// NOTE: 此处必须先解除播放器输出关联，再销毁播放器
```

- 已完成的 TODO 必须删除
- 较大的待办事项写入 `docs/`，不长期留在源码中
