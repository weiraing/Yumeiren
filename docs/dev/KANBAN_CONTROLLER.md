# 看板娘控制器维护说明

## 职责划分

| 文件 | 职责 |
|------|------|
| `KanbanController.h` | 界面与托盘使用的公共接口、所有权和设置镜像 |
| `KanbanController.cpp` | 后端选择、窗口组装、状态广播、启动与退出 |
| `KanbanControllerSettings.cpp` | 配置迁移、设置读写、模型选择、窗口几何 |
| `KanbanControllerInteraction.cpp` | 动作、表情、帧推进和光标坐标转换 |
| `KanbanAnimationClock.*` | 动画计时、每秒帧率统计与停止归零通知 |

实现文件共享同一个控制器，不新增代理对象、定时器或配置副本。
只有窗口组装代码和控制器持有后端引用，界面不接触 Cubism SDK。
首次落位与后续缩放共用尺寸计算，缩放固定底边中心。
自有文件和类使用 PascalCase，函数与局部变量使用 camelCase，
成员使用 `m_` 前缀，常量使用 `kPascalCase`，命名空间使用小写。

## 行为约束

- 正常退出保留 `kanban/enabled`，用户停止或启动失败时清除。
- 仅在 `gazeStrength` 缺失时迁移旧开关，新键优先。
- 修改视线档位时同步旧键，以支持回退旧版本。
- GL 资源在窗口销毁前释放；GL 初始化回调中的启动收尾延后到事件循环。
- 隐藏窗口停止动画时钟，但不等同于用户停止看板娘。
- 缺少动作或表情不能隐式切换模型。

## 配置回归

```powershell
cmake -S . -B build -DYUMEIREN_BUILD_CONTROLLER_TESTS=ON
cmake --build build --target KanbanControllerTest -j 1
ctest --test-dir build -R KanbanControllerSettings --output-on-failure
```

测试默认关闭，不依赖 Cubism SDK，不创建桌面窗口。
可执行文件及测试配置放在 `build/tests/<配置>/controller-test` 中，
不读取或清理产品配置，也不执行旧注册表迁移。

覆盖首次启动默认值、旧视线键迁移及优先级、视线四档边界、
缩放/透明度/帧率限值、配置回读、未知模型拒绝、停止状态下的交互，
以及重复退出保留设置、显式停止清除设置。
另验证时钟统计经控制器转发、停止归零、重复停止幂等、重启恢复通知。
测试使用事件循环，不依赖桌面或 OpenGL；帧率指动画推进频率，不是 GPU 呈现频率。

## 状态刷新

时钟每秒统计后发出 `measuredFpsChanged`，控制器转发给页面。
页面仅调用 `updateKanbanStatus()` 更新文本，不逐帧回填滑块、扫描模型列表或刷新托盘。
修复了启动时状态行读取初始零值、之后长期不更新的问题。
计时器使用值成员，避免原先动态分配 `QElapsedTimer` 后未释放。
