# 视频壁纸模块重构：优化前后对比（Phase 7）

- 前（基线）：commit `d0cbbb0` 构建；后（重构后）：工作区改动构建（见本次提交）。
- 环境、方法、口径与 [perf-baseline.md](perf-baseline.md) 完全一致；原始数据 `tools/perf/results/`（`s*` 为基线，`*r` 为重构后，`e1/e2` 为新增错误恢复测试）。
- 本次重构**不改动解码/呈现后端**（仍为 Qt Multimedia FFmpeg + QVideoWidget），因此播放开销与框架固有成本持平，重构收益集中在正确性与健壮性。

## 未解决问题与后续建议

1. **多显示器两处修复（#2/#6）与锁屏/熄屏/Explorer 重启场景**在本机（单屏）无法复现，需接双屏人工验证一次。
2. 4K60 的 ~1.5GB Private / 1.4GB 显存来自 Qt FFmpeg 后端帧池，属框架固有成本；如需压低，评估方向是限制解码线程数/帧池大小（Qt 无公开 API，需后端补丁或改自研管线），当前不建议动。
3. "帧率上限"仍是 playbackRate 慢动词语义（基线 S4 实证：省显存不改解码 CPU）。若要真正的"降帧渲染"需 QVideoSink 自绘管线（P3，暂缓）。
4. 壁纸右键菜单、视频信息展示（分辨率/时长/编码）、播放进度条仍未实现（A2/A3，可选增强）。
5. 暂停/继续按钮的"继续"文字翻转依赖 playbackStateChanged 触发 updateVideoButtons，自动挂起→恢复路径下按钮文字可能滞后一拍（纯显示问题）。
